# Al Madina Hospital & Maternity Home — React Website

## Run
1. Extract the ZIP.
2. Open PowerShell in this folder.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local Vite URL (usually http://localhost:5173)

## Notes
- Main service artwork is stored locally in `public/images` for fast loading.
- The About/Gallery hospital-building image is loaded from the hospital's own public website so it is a real Al Madina Hospital image rather than a mockup.
- WhatsApp appointment buttons open +92 300 6979966 with pre-filled messages.
- Facebook currently blocks automated image retrieval, so Facebook photos were not copied into the package. They can be added later to `public/images` and the gallery array in `src/main.jsx`.
